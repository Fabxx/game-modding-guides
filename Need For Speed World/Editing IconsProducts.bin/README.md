# REQUIREMENTS

- [Need For Speed World Unlimiter](https://github.com/NFSTools/NFSWorldUnlimiter)

- [Hex2Cmp](https://www.fairdell.com/hexcmp/)


# Editing the file

- Open IconsProducts.bin with TexEd and replace the textures

- Save the file and make sure you have a backup of the vanilla file

- Open both vanilla and modded files into Hex2Cmp

- Restore the vanilla header in the file, then scroll down a bit and restore a good chunk of bytes from vanilla
   into the modded file. TexEd changes a lot of bytes with garbage data and this will make the game crash.
